# HOME AI Core Modules

Официальный приватный каталог модулей HOME AI Core.

Этот репозиторий хранит только метаданные опубликованных модулей. Исходный код модулей и Docker-образы находятся в их собственных репозиториях/GHCR.

## Структура

- `catalog.json` — индекс доступных модулей, который читает HOME AI Core.
- `modules/<module-id>/manifest.json` — Manifest v2 опубликованной версии модуля.
- `schemas/catalog-v1.schema.json` — схема каталога.

## Правила публикации

1. Модуль должен использовать immutable Docker image вида `image@sha256:...`.
2. Версия должна быть совместима с указанной версией HOME AI Core.
3. В пользовательском интерфейсе отображаются только модули, присутствующие в `catalog.json`.
4. Обновление каталога выполняется только после успешной сборки и проверки Docker-образа.
